# NFTMint

Simplifies NFT creation and management for developers and artists with a user-friendly web interface.

With NFTMint, you get a lightweight tool that stays out of your way.

**What you get**

- Simplifies NFT creation and management
- for developers and artists with
- a user-friendly web interface

## Key Features

- Simplifies NFT creation and management
- for developers and artists with
- a user-friendly web interface

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/NFTMint.git`
2. `cd NFTMint`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
